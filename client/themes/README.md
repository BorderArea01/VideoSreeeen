# 主题源码唯一入口

维护指南与完整接入示例见 [主题框架](../../../docs/theme-framework.md)。

- `classic/`：常驻的默认主题和应用基础控件样式。
- `core/`：契约、注册表、加载 / 装卸控制器、资源生命周期和通用选择界面。
- `shared/`：显式共享的面板布局与 CSS、悬停抽样；不导入任何扩展主题。
- `daylight/`：天光断层的清单、入口、布局样式、控件、场景、断层绘制和天空资产。兼容已保存的主题 ID `glitch`。
- `signal/`：紫电噪讯的清单、入口、样式、动画、场景与字体资产。

扩展主题只从自己的 `manifest.ts` / `index.ts` 接入。不得新增根目录旧主题文件、全局补丁、`v2` 并行实现或跨主题私有导入；修改到本主题现有职责文件。共享需求先抽到 `shared/`，经 `core/ThemeScope` 管理所有运行时资源。注册表自动发现清单，选择界面由清单生成。
