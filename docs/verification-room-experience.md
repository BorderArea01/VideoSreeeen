# 共同播放内的缓存、真实 RTT 与聊天弹幕

2026-10-19，版本 0.4.2。保持共享画面、共同播放、本地视频三条路径和零付费授权；不操作 Android 设备，不读取真实账号 Cookie。

## 发现与实现

- 原先底部 RTT 是客户端 ping/pong，而列表 RTT 在 Node 使用 WebSocket 控制帧、在 Worker 使用另一次应用层挑战，测量路径与时刻不同。没有样本年龄时旧数字也会长期保留。现在 Node / Worker 都通过随机一次性 nonce 的应用层挑战测量，丢弃错误、重复、过期与过密请求，服务端公布同一批 RTT 与相对样本年龄。约 5 秒采样、15 秒过期，列表和底部在同一渲染调用更新；小于 1ms 显示 `<1 ms`，无有效样本显示 `—`，悬停说明并非画面延迟。
- 高频 RTT 曾通过整份 room state 广播，触发客户端解除待确认操作、重建播放锚点。新增可协商的 `latency-v1` 能力与独立通知，不修改播放版本；旧客户端继续收到其能理解的状态。客户端本地 ping 只供播放时钟的传输估计，不再作为另一份显示数字。pong 携带媒体、代次及播放版本标记的轻量时钟，只有当前媒体与播放版本一致且无待确认操作时才校准，保留长时间播放的定期时钟校准，不用遥测确认人工控制。
- 共同缓存入口移入共同播放面板，说明适用场景和浏览器 128 MiB 上限；实时画面没有缓存分支，没有可下载源时禁用开关。点击方式标签仍只改变输入面板，不暗改当前影片，缓存默认关闭并继续使用完整落盘与全员指纹门槛。
- 聊天弹幕从已确认的聊天记录增量生成，只取新文字与 Emoji；不发送乐观本地副本，不重放历史、重连消息或关闭期间消息。文本使用 `textContent`，不执行 HTML；按字素裁剪至 80 个，避免截断组合 Emoji。最多 5 轨、24 个活动节点、20 条积压，积压过 4 秒丢弃。恒定轨道速度与占用间距避免追尾；只作用于视频可见区域，暂停视频时仍按实时聊天飘过。
- 网页弹幕位于播放器容器内，支持容器全屏与隐藏聊天室。Windows 使用本应用无桥接、无外网权限、穿透鼠标的透明子窗口；Android 使用无应用桥接、禁止外网、触摸穿透的独立本地 WebView。不会向原站页面注入聊天室文字，也不把弹幕编码进提供给观众的原站画面，避免二次叠加。

实现参考 [MDN Web Animations](https://developer.mozilla.org/en-US/docs/Web/API/Web_Animations_API/Using_the_Web_Animations_API)、[全屏容器规则](https://developer.mozilla.org/en-US/docs/Web/API/Fullscreen_API/Guide) 和 [DPlayer 原生弹幕实现](https://github.com/DIYgod/DPlayer/blob/master/src/js/danmaku.js) 的轨道管理思路。没有引入新依赖或复制第三方代码。测试网络延时仅使用 [Playwright WebSocketRoute](https://playwright.dev/docs/api/class-websocketroute) 代理真实服务器的探测回应，产品里没有注入数字或模拟在线用户。

## 已完成验证

- 55 项测试及前端 / Node / Worker 类型、构建、Worker dry-run 通过。新增覆盖历史去重、组合 Emoji、nonce 伪造与重放、探测频率、过期、跨客户端同源显示、旧连接不得写入、延迟不推进播放版本及旧客户端兼容。另有 Windows 覆盖窗口加载期间被清理时，迟到旧评论不得重新出现的回归测试；最后增加的测试另行通过类型检查。
- 双隔离浏览器通过实际视频解码、缓存入口切换与手动门槛、文字 / Emoji 弹幕移动、纯文本 HTML 字样、隐藏聊天室、开关不补播、全屏和手机宽度。测试把一端的探测回应延后 160ms，两端列表一致显示实测约 194ms，底部与本人项一致；停止探测回应后 16 秒两端旧数字全部隐藏。没有页面错误，截图已目视确认实际可见文字，非仅检查 DOM 节点存在。命令 `npm run test:chat-overlay`，默认 Node 本地房间，正式网页可通过 `VS_PUBLIC_URL` 指定。
- Windows 实际原站桥接加网页观众使用 CC0 样片通过；暂停、1 秒位置、1.5 倍速稳定，浏览器解码 960×540 / 70 帧。原站弹幕在独立本地窗口实际出现并可关闭；读取测试原站 DOM 未发现聊天文字。此项是本地原站样片，不能替代 B 站或蜜柑本轮实站回归。命令 `npm run test:native-sync`。
- workerd / Pages Service Binding 测试通过：应用层 RTT、休眠恢复、原图 2 MiB、聊天、视频二进制转发、成员隔离及停止清理；没有启用原站 HTTP 视频代理。

首次正式测试在上一条操作尚未确认时切换缓存，触发版本冲突；验收脚本改为核对双方权威播放与模式状态后继续。后续真实公网测试发现取消缓存时的迟到 P2P 信令报错：现在服务端丢弃已认证成员的旧代次信令，不转发、不回传播放错误；当前代次非法信令与未来代次仍拒绝。客户端同时按 Peer 对象身份阻止旧 offer / ICE 回调借用新代次发送，新增回归测试。

证据保存在 `.local/chat-overlay-evidence.json`、`.local/native-sync-evidence.json` 和相关截图，不提交会话资料、视频字节、临时签名或令牌。后续追加最终构建、部署与客户端结果；尚未声明 Android 真机或 Safari/iOS 通过。
