# 2026-11-01 稀饭电影识别与首帧等待

用户链接为 `https://next.xifanacg.com/anime/1699/play/25828?source=xfy2`，原站片名《凉宫春日的消失》。原有识别规则没有区分或拒绝电影；原站匿名公开播放接口实际返回同片、同集、同线路的 MP4。文件大小 1,912,386,634 字节，实际播放时长约 9707.7 秒；浏览器收到起始与尾部范围的 HTTP 206 响应，需要读取文件尾部索引。

## 问题与修订

旧网页源码 `ee23f31` 将地址识别及首帧检查合并到同一个 15 秒的 AbortSignal。即使接口已经返回有效地址，只要首帧还未就绪，也会中止并显示“原站视频源暂未识别，请重试或使用共享画面”。

在正式入口的独立双人房间，仅延迟测试提供者的 CDN 请求 17 秒，原 API、签发地址与视频内容均不修改，可以稳定复现这条相同错误；16 秒观测时已退出检查，发布换片指令为 0。用户报错本身没有标明底层异常，因此此复现证明现有缺陷，不代表已排除用户网络上同时存在的其他问题。

修订为：地址识别保留独立 15 秒，识别成功后首帧单独最多等待 60 秒；不等待完整下载。阶段超时分别提示“原站播放接口响应超时”与“视频地址已识别，但首帧加载超时”，接口网络错误也单独提示。取消、换输入方式、离线或媒体发生变化仍中止旧任务，成功加载画面前不发布换片。

未修改线路 ID、CDN 许可、原站签名或请求头，不转发影片经过房间服务器，不新增电影专用绕行或访问权限。
