# 2026-10-31 天光断层边角与按钮统一

用户截图显示：邀请按钮旁、语音入口旁的断层被规则矩形截断；同步链接以外的按钮缺少一致的故障样式。

## 修正

- 移除聊天室整块标题操作区及语音 summary 的保护矩形，也不再把按钮整个中心矩形从装饰层擦掉。使用可见文字的 Range.getClientRects()、可见 SVG 和小标记的实际范围保护文字与相邻图标，保留其外侧边缘的连续条块。参考 [MDN Range.getClientRects](https://developer.mozilla.org/en-US/docs/Web/API/Range/getClientRects)。
- 按钮、展开菜单、按钮语义控件与按钮式链接共用原有瞬时故障时序；不再仅限定几个带 .button 的入口。邀请、播放方式、语音、设置、发送和收起均有自身的表面 / 标签 / 图标合成切片，真实控件的坐标、事件和标签不改。透明按钮保持透明底片，不产生实心浅色矩形贴片。
- 「发送」使用 CSS 伪元素文字，补齐该文字的合成绘制。天光旧规则还隐藏了聊天室所有后代 SVG，改为只隐藏标题自身的装饰图标，恢复邀请和收起按钮图标。
- 视频及其控制栏、输入框、选择框、聊天消息和已展开的业务弹层保留完整保护。只绘制本应用主题素材和自有控件，不读取影片或第三方像素、不改变房间状态。每次交互约 840 ms，最多保留 8 次交互、120 个候选宿主；无活动时停止绘制，减少动态效果和全屏沿用原保护。

## 本地验收

受控入口串行执行 npm run build、npm run test:appearance、npm run test:signal-theme，均通过。测试使用新建双端房间、MDN CC0 视频和隔离浏览器；未操作用户观影房间、物理麦克风或设备。

- 六类新增 / 恢复动效的控件实际画布像素非空，真实控件边界在悬停前后完全相同：邀请 989、共同播放 2187、语音 1232、设置 241、发送 685、收起 123 个有效像素。数值为此次实测时刻，不作为视觉效果固定参数。
- 聊天室右上角原来被整块擦除的区域，测得 574 个断层像素。已目视检查邀请、语音、共同播放及聊天室上边角的实际截图。
- 同步链接的图标与文字仍有共同的窄行切片，静止后画布恢复透明；保留照片实时采样和独立于鼠标的有限余迹。
- 双端视频 / 语音收听保持、真实聊天传递、收起 / 展开、320 / 390 窄屏、缩放、两种全屏、减少动态效果、强制颜色与视频 / 输入区域保护通过。C 的「任何按钮点击触发背景、悬停背景不触发」也通过回归。
