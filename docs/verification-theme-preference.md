# 2026-11-02 主题选择保持与原版默认

旧行为只把手动选择写入 `videosreeeen.appearance`；没有有效偏好时，新导航随机分配主题，同标签刷新才复用 sessionStorage。点击「随机选择」还会删除已保存偏好。这使没有主动固定主题的老用户在新标签或再次访问时遭遇不同布局。

现在由 `client/appearance.ts` 统一处理偏好：没有有效本机记录时使用注册表默认主题（当前为暖夜原版）；保留已有手动选择；旧的随机 session 不再影响默认。手动选择和「随机换一个」都在主题成功应用后保存结果，不再开启后续自动随机。显式 `?skin=` 链接仍会选择并保存指定主题。浏览器禁止存储时仍可当次切换，但无法承诺跨访问保存；清除网站数据也会清除偏好。

主题注册、加载、生命周期和各主题布局没有增加分支，不修改房间状态或广播其他成员的选择。默认主题保持常驻，扩展仍按需加载。

## 验证

- `npm run build`：TypeScript、网页和既有打包入口通过；浏览器助手 ZIP 内容未变化。
- `npm run test:theme-preference`：独立 Edge 上覆盖无记录、暖夜、天光、紫电及已移除主题记录；分别检查刷新、新标签和通过保存的 storageState 恢复新浏览器上下文。旧随机 session 不覆盖当前选择，主动随机结果保持，选回暖夜后继续保持；存储被阻止时仍可切换。
- `npm run test:theme-framework`：24 次切换、移除 / 插入、第三主题、迟到加载与资源释放通过；原应用和媒体节点不变，没有额外媒体加载或房间操作。
- `tests/theme-framework.test.ts`：7 项通过。设置面板截图经目视核对，保留「暖夜 原版」入口和新的记忆说明。

测试使用隔离浏览器，不使用用户浏览器配置，不进入正在观看的房间，不产生真实麦克风录音。storageState 恢复验证等同于恢复已保存的本机偏好，不伪称已重启用户的物理浏览器。没有新增手机真机结论。
