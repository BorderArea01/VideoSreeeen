- 类型检查、共享界面和 Node 服务端构建通过。
- 15 项自动测试通过：真实 WebSocket 建房/加入/双端聊天、浏览器和 Windows 文件来源、邀请鉴权、控制冲突和去重、断线恢复、旧缓存代次、内容指纹、结束/离开清理、磁盘 Range 读取、下载中断与路径边界、原站手动操作和回声抑制、HLS 基础验证。

## 资源与隔离

所有本机构建和浏览器验收经受控入口串行执行；检查实际游戏进程、可用内存，监测中途变化，只清理本轮进程。没有按 QQ/网页标题误判游戏；没有操作其他 Android 设备、关闭其他项目或全局终止 Java。

详细自动证据位于本机 `.local/ui-evidence.json`、`.local/package-evidence.json`（成品验收通过后生成），截图位于 `.local/screenshots/`。这些文件可能包含临时邀请或本机网络地址，不提交仓库。
