# 手机共同播放加载失败与本机恢复

2026-10-20 用户反馈：Android Edge 浏览器中，房间三人在线，AL 页面 `3434/play/203799?source=AL` 显示“当前视频地址无法直接播放”。用户已确认仍是该视频。此现场失败优先于此前同电脑双端的成功结果；不能将 Windows 浏览器视口模拟称为 Android 真机通过。

## 已取得的证据

- 使用全新移动浏览器资料、同一正式入口和同一视频，晚加入后本机 Windows Edge 实际解码出 1920×1080 / 15 帧。CDP `Media` 属性表明视频为 **HEVC Main**，使用平台 `VDAVideoDecoder`；音频为 AAC。移动 UA 模拟仍使用 Windows 的实际解码器，不能证明用户手机能解码。
- 视频从 `play.xfvod.pro:8088` 加载。用户手机的真实 HTTP / 网络失败或解码错误尚未取得；不能仅凭这个端口、VPN 图标或截图判定运营商封锁、源站限制或 HEVC 不兼容。
- 原站公开元数据还列出 CS 线路 2，正常页面调用同一公开接口后返回另一个 CDN；本机该页面未加载出可播放视频，未将其加入支持或作为默认兜底。
- 原实现 `sourceFailed` 一旦设置，就隐藏视频、禁用控制，仅显示共享画面和本地文件建议；没有独立的本机重试。原诊断只覆盖画面共享，直链视频即使绑定也显示 `transport=none`，不包含 `MediaError` 或编解码能力。

## 本轮改动

- 共同播放失败界面提供“重试本机视频”和“复制诊断”，不再要求手机提供画面或更换全房间视频。
- 重试只重新加载该设备；稀饭直连播放时通过既有匿名公开接口重新签发同剧集、同线路源，保留现有白名单、期限、取消和大小校验。房间媒体、播放版本、缓存代次不变，不发暂停、播放或换片命令。
- 重试限时 20 秒，失败可再次手动重试；换片、换模式或离开后取消，迟到结果不得恢复旧视频。未引入后台无限重试。
- 有效首帧恢复时解除失败界面；资源重置后没有真实错误的排队事件不再覆盖当前播放状态。
- 错误提示区分下载中断、解码失败和超时；错误 4 仍可能涵盖连接、源响应或格式问题，不直接断言权限故障。
- 诊断记录真实错误码、视频／音频轨道、网络状态、直连／代理／缓存／共享传输和 H.264 / HEVC / AAC 的浏览器能力声明。能力声明不等于实际解码成功。只保留源协议、域名和端口，剔除路径、查询、凭据、原始底层错误消息；不上传服务器。

## 验证

`npm run verify` 通过 65 项测试、格式、前端 / Node 构建、Worker 类型检查和 dry-run。新增用例覆盖诊断脱敏、错误分类与取消后的首帧等待隔离。

`npm run test:playback-retry` 使用真实原站 API / CDN、独立移动浏览器资料和本地真实房间服务；仅阻断测试观众的媒体请求，产生真实错误 4：

- 第一次手动重试仍被阻断，失败界面与可再次重试按钮保留。
- 复制诊断包含错误 4、直连、CDN 和 8088 端口，不包含视频路径、签发参数或 Cookie。
- 解除测试网络阻断后再次重试，恢复首帧和后续解码；房间媒体 ID 和播放版本不变，观众未发出房间控制或换片命令。
- 将观众重新置于失败状态并延迟刷新接口，房主换片后取消观众重试；新视频正常加载，旧请求不能替换它。
- 无页面错误。仍未完成用户手机上的实际错误诊断，不宣称已修复该手机的 HEVC 解码或网络连通问题。

错误含义依据：[HTML Standard MediaError](https://html.spec.whatwg.org/multipage/media.html#error-codes)。真实 Android 设备未安装或操作。
