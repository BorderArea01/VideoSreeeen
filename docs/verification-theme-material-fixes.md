# 2026-11-03 主题材质残留、邀请对齐与天光边缘断层

统一布局时保留了默认欢迎场景的月亮、斜线与楼影；邀请入口又沿用只给上方留白的链接样式，与扩展主题的完整按钮边框叠加后偏离中心。天光旧的标题白底板和右侧独立底板没有按统一顶栏重新配套。聊天输入框整块处于装饰保护区，旧文字 / 图标切片函数则仍在按钮上运行。

## 实现

- 默认场景以 `--welcome-*` 材质变量提供原版效果；扩展主题覆盖透明度和背景，清除月亮、线条和楼影，不隐藏真实控件或改变布局。天光品牌图标使用本主题蓝白色。
- 公共 `.invite-line` 使用对称内边距、完整边框和原有 flex 居中，修复所有主题的邀请入口。
- 天光顶栏使用连贯的浅色半透明底，删除品牌白底伪元素，右侧操作区不再单独铺底。标题、状态、设置和创建 / 邀请按钮保持默认位置。
- 天光按钮统一调用边缘 `fractureEdge`，删除旧 `controlPlate` / `fractureControl` 文字图标切片实现。文字与图标在每个动画帧都擦除装饰覆盖；保留悬停约 50% 概率及幅度变化。
- 聊天输入框和组合输入区域作为材质边缘参与断层；文本内部、安全边距和光标保留。仅读取边框几何及颜色，不读取或绘制输入值。普通播放底栏可使用同一边缘效果，实际影片区域、弹窗、输入正文继续被保护；全屏保持暂停装饰动效。

## 验证

`test:theme-layout` 在 zh-CN / Asia/Shanghai 的独立 Windows Edge 验证三主题、1440 / 850 / 390 / 320 px 共 16 组切换：布局、控件宽度与原节点身份保持；额外断言默认装饰只在原版出现，邀请上下留白对称、图标居中，天光不存在左右两块标题 / 操作区底板。截图经目视检查。窄屏是浏览器模拟，不是手机真机结论。

`test:appearance` 的双端播放、语音接收、聊天、折叠、主题偏好、减少动态效果、强制配色、全屏及影片像素保护通过。按新需求将旧文字切片断言替换为“文字 / 图标所有采样帧覆盖为 0”，保留边缘像素和不位移检查。聊天输入框测得边缘断层 2302 个像素，内部覆盖为 0，值和光标选区保持一致。原始结果在 `.local/appearance-evidence.json` 和 `.local/theme-layout-local.json`。
