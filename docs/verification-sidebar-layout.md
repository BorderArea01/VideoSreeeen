## 原因与实现

- 原语音卡片虽然有 z-index，但它位于 source-card 的独立层叠上下文内；后方成员菜单作为另一上下文绘制到它上面。保留装饰隔离，在实际展开语音时提升整个 source-card；成员与语音面板互斥，点击外部或 Esc 关闭，窄屏横向定位约束在视口内，长列表内部滚动。参考 [MDN 层叠上下文](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Positioned_layout/Stacking_context)。
- 移除标题栏 pointer capture、拖拽悬浮按钮、坐标与旧浮动样式。三款主题统一使用收起箭头，右侧边缘「聊天室」展开；宽屏视频扩展，窄屏仍保持单列。保留聊天、输入草稿、播放器及语音 DOM；不发布房间控制、换片或模式消息。网页全屏仍可用自己的聊天按钮，退出恢复原来的收起状态。
- 收起状态只属于本机，不修改其他成员的主题或房间状态，不强制刷新当前观影页面。
