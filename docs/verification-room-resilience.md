# 房间语音恢复、票选与分批清理（2026-10-31）

本轮在独立 Node 房间、独立浏览器资料与合成音视频中验证，不加入或控制用户正在观看的房间。网页和房间服务集中更新，Windows / Android 的 v0.4.6 Release 八项资产保持不变。

## 行为

- 语音 WebSocket、房间 WebSocket 短暂断开：保留用户在本标签页主动开启的有效麦克风流，断线期间禁用音轨、清空积压，恢复身份后重建编解码和接收缓冲。不会重复申请麦克风；主动静音、离开、刷新、身份失效、硬件断开仍不自动开麦。编码器异常可恢复兼容编码；单人的解码积压仅重置其接收缓冲。浏览器音频中断尽量复用已有 AudioContext，仍可能需要一次恢复手势，不能承诺锁屏持续通话。
- 成员行「⋯」发起，聊天室显示投票。至少 3 人在线，60 秒，固定在线名单严格过半同意；重复票替换原票，目标不能同意移出自己，过期或在线名单变化取消，结束冷却 30 秒。通过后删除成员权限、断开连接、停止其语音，旧恢复凭据的哈希保存在服务端并参与恢复检查。昵称、IP、浏览器之外没有可靠账号身份，不能阻止持有邀请者创建新身份；不宣称永久封禁。
- 新版分批模式先核对全员能力与首批内容；根据原 MP4 样本表、时间表、编辑列表和关键帧，或平面 DASH sidx，计算真实可用范围。播放越过该批所有音视频样本的安全边界，且后续批次已经落盘，才删除实际块文件并撤回 P2P 库存。元数据保留到片尾清理。灰色区域表示全员尚未保留或已删除的范围，拖动、预览、前后跳转和服务端控制均拒绝跳入；亮色范围取全员交集。没有可靠索引则拒绝清理并提示完整缓存。
- 删除前已用增量 SHA-256 消费块内容，后续整片指纹仍可跨端核对；不把历史校验记录当作当前磁盘库存。完整缓存保留全部回看能力。旧版分批房间不自动切换，需全员更新后重新启用；HLS / 旧 Android 仍完整缓存。

## 隔离验收

- `npm run test:voice`：三个真实浏览器音频上下文，合成麦克风，物理输出静音；双向与三方真实解码、180 ms 抖动、兼容编码、设备选择、人声优先、退出释放通过。额外强制关闭语音和房间 WebSocket，均恢复原麦克风且 getUserMedia 次数不增加，双方继续接收音频。
- `npm run test:moderation`：三份浏览器资料，第三位开启合成麦克风；发起与表决、固定聊天室高度、投票期间聊天、通过后退出并释放轨道、其他两端继续播放通过。
- `npm run test:cache-window`：12 秒合成 H.264 / AAC MP4，故意阻塞最后一批。两端只落盘 1,835,008 / 4,767,914 字节已解码播放；继续到约 6 秒，完成 3,407,872 字节下载后各自删除一批，实际保留约 1,835,008 字节。全员可跳转窗口约为 5–8.42 秒，拖入 0 秒无控制消息，窗口内跳转成功。之后完成整片指纹比较、播放结束清理、完整缓存回归、目录记忆通过。房主使用授权目录分块路径，观众使用 OPFS 分块路径；两者都实际删除文件。
- 单元测试新增真实样本 / sidx 边界、未知索引拒绝、全员窗口交集和无交集关闭门槛、服务端越界拒绝、Windows 实际分块删除 / 读取撤销 / 相邻文件保护，以及票数、过期、冷却、旧凭据和恢复检查。
- `npm run verify` 的 113 项单元测试、格式、类型、前端 / Node 构建、Worker 类型及 dry-run 通过；最终界面调整后再次构建通过。`test:worker` 另经实际 workerd 休眠恢复验证票选、撤销凭据及缓存窗口持久化，越界跳转拒绝。
- `test:cache-download` 完整缓存失败重试、指纹和片尾清理通过；`test:p2p` 浏览器互传、损坏数据拒绝、同时下载、Windows 双向落盘互传与退出清理通过。`test:cache-location` 使用真实 D 盘独立资料目录，额外验证 Windows 分块文件删除 1,572,864 字节后继续本机解码、可用范围内跳转、已删块读取失败和相邻用户文件保留。
- 语音另覆盖 AudioContext 暂停恢复、编码器异常切换兼容编码，以及静音后断线仍保持静音，均不增加麦克风授权次数；票选在 390px 视口保留完整输入 / 发送区，无横向溢出，属于桌面浏览器布局验收。

原始证据在忽略目录 `.local/voice-local-evidence.json`、`.local/moderation-evidence.json`、`.local/cache-window-evidence.json`，截图在 `.local/screenshots/`。这些是桌面 Edge 和 Electron 源码路径证据，不能代替手机硬件、运营商网络和长期实片验收。
